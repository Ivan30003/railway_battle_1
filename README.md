# Паровоз

2D top-down survival / tower defence на рельсах. Проект на Python + pygame-ce.

Сейчас реализован **milestone 1** — карта и маршрут:

- запускаемый скелет (окно, fixed-timestep цикл, сцены, ввод, конфиг);
- текстовый формат карт и строгий парсер с понятными ошибками;
- проверка, что все рельсы образуют один замкнутый цикл из `START` по `DIR`;
- построение маршрута с параметризацией по длине дуги;
- процедурная отрисовка рельсов, сетки, стартовой стрелки (в debug) и
  движущегося маркера паровоза.

Поезд с вагонами, монстры и магазин появятся в следующих milestone'ах.

## Быстрый запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt

python -m game
```

Окружение `.venv` уже создано в репозитории и исключено из git.

Полезные варианты запуска:

```bash
python -m game --debug                 # сразу с debug-overlay
python -m game --scene game            # сразу игровая сцена
python -m game --scene shop            # игровая сцена с открытым магазином
python -m game --scene gameover        # превью экрана поражения
python -m game --scene victory         # превью экрана победы
python -m game --map maps/map2.txt     # конкретная карта
python -m game --headless-frames 3     # smoke-запуск с dummy SDL
```

## Управление (milestone 1)

| Действие | Ввод |
|---|---|
| Подтвердить / играть | `Enter`, `Space`, ЛКМ по кнопке |
| Меню / закрыть магазин | `Esc` |
| Магазин | `B` или кнопка «Магазин» в HUD |
| Пауза | `Esc` в игровой сцене |
| Debug-overlay | `F1` |
| В главное меню | `M` |
| Выход | `Esc` в меню, `Ctrl+Q`, закрытие окна |

Маркер паровоза сам движется по замкнутому маршруту со скоростью
`train_speed` из конфига. На паузе и в магазине движение останавливается.
Магазин пока является заглушкой: покупки будут реализованы в milestone 6.

## Карты и маршрут

Карты лежат в `maps/`. Формат:

```text
# комментарий
START=1,1
DIR=RIGHT
00 RD SH LD 00
00 SV 00 SV 00
00 RU SH LU 00
```

- `START=x,y` — координаты стартового тайла, `x` — столбец, `y` — строка,
  отсчёт с нуля;
- `DIR=UP|RIGHT|DOWN|LEFT` — направление, в котором поезд покидает стартовый
  тайл;
- остальные непустые строки — токены тайлов, разделённые пробелами.

Поддерживаются комментарии `#`, пустые строки, CRLF и UTF-8 BOM. Заголовки
могут идти в любом порядке до первой строки сетки.

| Токен | Значение |
|---|---|
| `00` | пустой тайл |
| `SV` | прямой вертикальный путь |
| `SH` | прямой горизонтальный путь |
| `X` | перекрёсток, поезд проходит прямо |
| `LD` | поворот вниз/влево |
| `RD` | поворот вниз/вправо |
| `LU` | поворот вверх/влево |
| `RU` | поворот вверх/вправо |

Парсер `game/core/map_loader.py` проверяет:

- размеры сетки и известность всех токенов;
- что `START` в пределах карты и указывает на рельс;
- что стартовый тайл соединяется в направлении `DIR`;
- что маршрут не выходит за карту и не упирается в пустой тайл;
- что маршрут возвращается в `START` с исходным направлением;
- что нет «осиротевших» рельсов, не входящих в цикл;
- что обычный тайл проходится ровно один раз, а `X` — не более двух раз
  (только навстречу друг другу под прямым углом, как в «восьмёрке»).

Ошибка загрузки карты печатается как `Map error: ...`, игра завершается с
кодом `2`.

Маршрут хранится в `game/core/path.py` как замкнутая ломаная. `sample(distance)`
возвращает позицию и единичный вектор направления, поэтому скорость поезда
не зависит от размера тайла и поворотов.

## Конфигурация

Все параметры — в `config/game.json`. Загрузчик `game/core/config.py`:

- подставляет значения по умолчанию для отсутствующих полей;
- глубоко сливает вложенные объекты;
- проверяет типы, диапазоны, типы вагонов, приоритеты и `reserve`;
- выдаёт `ConfigError` с понятным сообщением.

Путь к конфигу можно переопределить: `python -m game --config path/to/game.json`.
Путь к карте — `--map`; без него берётся первый файл из `maps` в конфиге.

## Структура

```
game/
  app/       запуск, цикл, сцены
  core/      чистая логика без pygame (конфиг, тайлы, парсер карт, маршрут)
  io/        события pygame → Action/InputState
  view/      renderer, камера, тема, UI, рельсы, debug-overlay
  assets/    загрузчик изображений и процедурные заглушки
config/      game.json
maps/        map1.txt, map2.txt
tests/       pytest
```

Слой `core` не импортирует pygame, поэтому карты и маршрут тестируются
headless.

## Виртуальное разрешение и окно

Виртуальный холст вычисляется из загруженной карты:
`ширина × tile_size` на `высота × tile_size`. Для карт 20×15 при `tile_size=32`
это 640×480. Холст масштабируется в окно 1280×960 с сохранением пропорций и
letterbox; окно можно менять в размерах.

## Ассеты

Сейчас используются процедурные заглушки из `game/assets/procedural.py`.
Чтобы подключить реальные изображения, положите PNG в `game/assets/images/`
и добавьте соответствие в `game/assets/manifest.json`:

```json
{
  "train/locomotive": "images/train/locomotive.png",
  "tile/SH": "images/tiles/SH.png"
}
```

Логические имена будут использоваться кодом; отсутствующие файлы автоматически
заменяются заглушками. Звуки пока не подключены.
